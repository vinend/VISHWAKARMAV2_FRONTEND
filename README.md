# VISHWAKARMA V2 FRONTEND

Welcome to the **VISHWAKARMA V2 Frontend** repository! This project is the frontend implementation for the Vertical Take-Off and Landing (VTOL) division of Universitas Indonesia's Aerial Unmanned Autonomous Vehicle (AUAV) team. Built with **React.js** and **Java**, this project is designed to showcase the capabilities and mission of the VTOL division.

## Key Features

- **Responsive Design**: A user-friendly interface that works seamlessly across various devices.
- **Modern Web Technologies**: Powered by React.js for dynamic and interactive user experiences.
- **Deployment-Ready**: Can be easily deployed for live demonstrations or public viewing.
- **Team-Focused**: Tailored for the VTOL division to highlight its innovations and milestones.

## Technology Stack

- **Frontend**: React.js
- **Backend**: Java 
- **Styling**: CSS/SCSS 

## Setup Instructions

Follow these steps to set up the project locally:

### Prerequisites

Ensure you have the following installed on your system:

- Node.js 
- npm or yarn
- Java (if backend services are required)

### Steps

1. **Clone the Repository**
   ```bash
   git clone https://github.com/vinend/VISHWAKARMAV2_FRONTEND.git
   ```
2. **Navigate to the Project Directory**
   ```bash
   cd VISHWAKARMAV2_FRONTEND
   ```
3. **Install Dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```
4. **Start the Development Server**
   ```bash
   npm start
   # or
   yarn start
   ```
   The application will be available at `http://localhost:3000`.

## Deployment

To deploy the project, follow these steps:

1. **Build the Project**

   ```bash
   npm run build
   # or
   yarn build
   ```

   This will generate the optimized production-ready build in the `build/` directory.

2. **Deploy**
   Deploy the contents of the `build/` directory to your preferred hosting provider, such as Vercel, Netlify, or AWS.
